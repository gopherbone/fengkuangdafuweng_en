# Crazy Tycoon English patch v1.0.0

> **AI translation.** This patch was made by an AI model (Anthropic's Claude), directed and play-tested by a human,
> and not reviewed by a fluent human translator. Please support human fan translators and their projects.

First release of the English translation of 瘋狂大富翁 (Feng Kuang Da Fu Weng) for Game Boy Color.

**Easiest:** patch in the browser at https://gopherbone.github.io/fengkuangdafuweng_en/

**Or** apply `crazy-tycoon-en.ips` to:

- `Feng Kuang Da Fu Weng (Unlicensed, Chinese) (Multicart Rip) [Header Fix].gbc`
- 2,097,152 bytes, CRC32 `AD68B3DD`, SHA-1 `72d3b05ca1bd08b646c3a3240fcc29f630958825`

The patched ROM should have CRC32 `4614544C`.

See the README for what's translated and the known issues.
